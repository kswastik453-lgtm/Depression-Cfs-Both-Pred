# ME/CFS and Depression Prediction System

The **ME/CFS and Depression Prediction System** is an interactive web application designed to assist in predicting potential health conditions based on patient
lifestyle, psychological, and physical health indicators.

The system allows users to enter health-related parameters such as:

- Sleep Quality
- Stress Level
- Brain Fog Severity
- Fatigue Scale Score
- Physical Pain Score
- Depression PHQ-9 Score
- Exercise Frequency
- Social Activity Level

The application then predicts outcomes using multiple trained Machine Learning models.

---

# 🎯 Objective

The primary objective of this project is to:

- Build an intelligent healthcare prediction system
- Compare multiple ML algorithms for prediction
- Create a user-friendly diagnostic interface using Streamlit
- Demonstrate practical usage of Machine Learning in healthcare analytics

---

# 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle

---

# ⚙️ Workflow / Process

1. Data preprocessing and feature engineering
2. Encoding categorical variables
3. Training multiple ML models:
   - Logistic Regression
   - Decision Tree
   - Random Forest
4. Saving trained models using Pickle
5. Building an interactive Streamlit web application
6. Taking user health inputs dynamically
7. Generating predictions based on selected ML model
